# タスク管理アプリ 要件定義書

## 1. 概要
トレロ(Trello)風の、シンプルなタスク管理アプリを作成する。
列(カラム)ごとにタスクカードを並べ、ドラッグ&ドロップで進捗を管理できるようにする。

## 2. 背景・目的
- Git / GitHub の操作練習と、実際に動くアプリ開発の両方を経験することを目的とする。
- まずは最小限の機能で「動くもの」を完成させることを優先し、必要に応じて機能を追加していく。

## 3. 対象ユーザー
- 開発者本人(個人利用)。複数人での共有・同時編集は想定しない。

## 4. 機能要件

### 4.1 カラム(列)機能
- 初期状態として「未着手」「進行中」「完了」の3列を表示する。
- ユーザーは列を自由に追加できる。
- ユーザーは列を削除できる。

### 4.2 タスクカード機能
各タスクカードは以下の情報を持つ。

| 項目 | 内容 | 入力方法 |
|---|---|---|
| タイトル | タスク名 | ユーザー入力(必須) |
| 詳細説明文 | タスクの補足情報 | ユーザー入力(任意) |
| 期限日 | 締め切り日 | ユーザー入力(任意) |
| 作成日時 | カード作成日時 | 自動記録 |

カードに対する操作:
- **追加**: 列を指定してタスクカードを新規作成できる
- **編集**: 既存のタスクカードのタイトル・詳細説明文・期限日を編集できる
- **削除**: タスクカードを削除できる
- **移動**: ドラッグ&ドロップで別の列へ移動できる

### 4.3 期限切れ表示
- 期限日が過ぎているタスクカードは、背景色や枠線などを赤系の色に変えて強調表示する。

## 5. 非機能要件
- データの保存先はブラウザの LocalStorage とする(サーバー・データベースは使用しない)。
- 対応環境: PCのモダンブラウザ(Chrome, Edge 等)を想定。スマートフォン対応は本バージョンでは考慮しない。
- 外部ライブラリ・フレームワークは使用せず、HTML / CSS / JavaScript のみで実装する。

## 6. データ設計(LocalStorageに保存する構造の案)

```json
{
  "columns": [
    {
      "id": "col-1",
      "name": "未着手",
      "cards": [
        {
          "id": "card-1",
          "title": "サンプルタスク",
          "description": "詳細説明文",
          "dueDate": "2026-10-01",
          "createdAt": "2026-09-27T10:00:00"
        }
      ]
    }
  ]
}
```

## 7. 画面構成イメージ

```
+--------------------------------------------------------------+
|  [+ 列を追加]                                                  |
|                                                                |
|  未着手           進行中           完了                        |
|  [+ タスク追加]   [+ タスク追加]   [+ タスク追加]                |
|  ┌──────┐      ┌──────┐      ┌──────┐               |
|  │タスクA │      │タスクC │      │タスクD │               |
|  │期限:.. │      │期限:.. │      │期限:.. │               |
|  └──────┘      └──────┘      └──────┘               |
|  ┌──────┐                                              |
|  │タスクB │(期限切れ→赤色)                                  |
|  └──────┘                                              |
+--------------------------------------------------------------+
```

## 8. 技術スタック
- HTML5
- CSS3
- JavaScript(素の JavaScript。フレームワーク不使用)
- データ保存: Web Storage API(LocalStorage)

## 9. スコープ外(今回は作らないもの)
- サーバーサイド・データベースとの連携
- 複数ユーザーでのデータ共有・ログイン機能
- スマートフォン向けのレイアウト最適化
- 列やカードの並び替え(ドラッグ&ドロップ以外の並び替え機能)

## 10. 今後の拡張候補(任意)
- カードにラベル(色分けタグ)を追加
- 列やカードの並び順を保存できるようにする
- 検索・フィルター機能
