## 1. はじめに

### 1.1 この文書の目的
本書は、無償で提供する「タスク管理アプリ」について、**何ができて、何ができないか**、**利用にあたっての前提・注意点**を提供先の方と共有するための文書です。
内容に相違や不明点がある場合は、利用開始前にご連絡ください。

### 1.2 アプリの概要
Trello のような「かんばん方式」のタスク管理アプリです。
画面上に列(例: 未着手・進行中・完了)を並べ、タスクを書いた「カード」をドラッグ&ドロップで動かすことで、仕事の進み具合を見える化できます。

### 1.3 導入によって期待できること
- やるべきことを一覧で把握でき、抜け漏れを防げる。
- 期限を過ぎたタスクが赤く表示され、対応漏れに気づける。
- インストールやアカウント登録が不要で、ブラウザで開くだけで使える。

### 1.4 想定する利用者・利用シーン
- **利用者**: 個人、または数人程度の少人数。特別なIT知識は不要です。
- **利用シーン**: 日々の作業管理、小規模なプロジェクトの進捗管理など。
- **重要な前提**: データは各利用者のブラウザ内に保存されるため、**利用者ごとに独立したタスクボード**になります(詳細は 6章)。複数人で同じボードを見る・同時に編集する用途には対応していません。

## 5. 機能要件

### 5.1 カラム(列)機能

| No. | 機能 | 仕様 |
|---|---|---|
| C-1 | 初期表示 | 初回起動時に「未着手」「進行中」「完了」の3列を表示する |
| C-2 | 列の追加 | 「+ 列を追加」から列名を入力して追加できる。列名は必須、1〜20文字。列数の上限は10列 |
| C-3 | 列の削除 | 列のメニューから削除できる。列内にカードがある場合は「カードも一緒に削除されます」と確認を表示し、了承した場合のみ削除する |

### 5.2 タスクカード機能

**カードが持つ情報**

| 項目 | 内容 | 入力 | 制約 |
|---|---|---|---|
| タイトル | タスク名 | 必須 | 1〜50文字 |
| 詳細説明文 | 補足情報 | 任意 | 500文字まで |
| 期限日 | 締め切り日 | 任意 | 日付形式(年/月/日)。過去の日付も入力可 |
| 作成日時 | カードを作った日時 | 自動記録 | 利用者は変更不可 |

**カードの操作**

| No. | 機能 | 仕様 |
|---|---|---|
| T-1 | 追加 | 各列の「+ タスク追加」から入力して追加する。追加したカードは列の末尾に並ぶ |
| T-2 | 編集 | カードをクリックして、タイトル・詳細説明文・期限日を変更できる |
| T-3 | 削除 | カードの削除ボタンで削除できる。削除前に確認を表示し、削除後は元に戻せない |
| T-4 | 移動 | ドラッグ&ドロップで別の列へ移動できる |

### 5.3 期限切れ表示

| No. | 機能 | 仕様 |
|---|---|---|
| D-1 | 期限切れの強調 | 期限日が今日より前のカードは、赤系の背景色と枠線で表示する |
| D-2 | 判定のタイミング | 画面を開いたとき・再読み込みしたとき、およびカードの追加・編集時に判定する(画面を開いたまま日付が変わった場合は、再読み込みで反映) |
| D-3 | 完了列のカード | 「完了」列にあるカードは、期限を過ぎていても強調表示しない |

### 5.4 基本的な操作の流れ

1. アプリを開く → 3つの列が表示される
2. 列の「+ タスク追加」を押す → タイトル等を入力して保存 → カードが列に追加される
3. 作業が進んだら、カードを次の列へドラッグ&ドロップする
4. 期限を過ぎると、カードが赤く表示される
5. 不要になったカードは削除する

## 6. 非機能要件・利用上の制約(必ずお読みください)

### 6.1 データの保存方法と、それによる制約
本アプリのデータは、**お使いのブラウザの中(LocalStorage)にのみ保存**されます。サーバーやクラウドにはデータを送信しません。そのため、次の点にご注意ください。

| 状況 | 結果 |
|---|---|
| ブラウザの「閲覧データの削除」で、サイトデータやCookieを消した | **タスクがすべて消えます** |
| シークレット(プライベート)ウィンドウで使った | ウィンドウを閉じるとタスクが消えます |
| 別のPCで開いた | タスクは表示されません(共有されません) |
| 同じPCでも別のブラウザ(ChromeとEdgeなど)で開いた | タスクは表示されません |
| 同じPCを複数人で共有し、同じブラウザ・同じユーザーアカウントで使った | 全員に同じタスクが見えます |
| ファイルの置き場所(フォルダ)を変えて開き直した | 別のアプリとして扱われ、タスクが表示されない場合があります |
| 保存容量の上限(目安5MB程度)を超えた | 保存できなくなります(通常の使い方では、数千件のカードまで問題ありません) |

**データ保護のためのお願い**
- 大切なタスクは、別途メモ等にも控えを残してください。
- 本バージョンにはバックアップ・復元機能はありません(拡張候補: 10章)。

### 6.2 対応環境

| 項目 | 内容 |
|---|---|
| 対応ブラウザ | Google Chrome、Microsoft Edge の最新版 |
| 対応端末 | Windows / Mac のPC |
| 非対応 | スマートフォン・タブレット、Internet Explorer、その他のブラウザ(動作する場合もありますが、確認・保証はしません) |
| ネットワーク | 不要(インターネットに接続していなくても使えます) |

### 6.3 性能・操作性
- カードが合計200件程度までは、操作の待ち時間を感じない動作を目標とします。
- 表示・操作はすべて日本語です。

### 6.4 セキュリティ・プライバシー
- ログイン機能はありません。**PCを操作できる人は誰でもタスクを閲覧・編集できます**。
- データを外部に送信しません。個人情報や機密情報の入力は、ご自身の判断と責任で行ってください。パスワードやマイナンバーなど、特に重要な情報の入力は避けてください。

### 6.5 実装方針
- 外部ライブラリ・フレームワークは使用せず、HTML / CSS / JavaScript のみで実装します(導入が簡単で、外部サービスの停止の影響を受けないため)。

## 8. 画面構成イメージ・導入手順

### 8.1 画面構成イメージ

```
+--------------------------------------------------------------+
|  [+ 列を追加]                                                  |
|                                                                |
|  未着手           進行中           完了                        |
|  [+ タスク追加]   [+ タスク追加]   [+ タスク追加]                |
|  ┌──────┐      ┌──────┐      ┌──────┐               |
|  │タスクA │      │タスクC │      │タスクD │               |
|  │期限:.. │      │期限:.. │      │期限:.. │               |
|  └──────┘      └──────┘      └──────┘               |
|  ┌──────┐                                              |
|  │タスクB │(期限切れ→赤色)                                  |
|  └──────┘                                              |
+--------------------------------------------------------------+
```

※ 上図はレイアウトの目安です。実際のデザインは開発中に調整することがあります。

### 8.2 導入・利用開始の手順

1. 提供されたファイル一式を、PC上の任意のフォルダに保存する。
2. `index.html` をダブルクリックして、Chrome または Edge で開く。
3. 3つの列が表示されれば、利用開始です。
4. 次回以降も、**同じ場所の同じファイル**を、**同じブラウザ**で開いてください(6.1 参照)。

インストール・アカウント登録・設定は不要です。

## 10. 対象外の事項と今後の拡張候補

### 10.1 今回は対応しないこと

| 対象外の事項 | 理由・影響 |
|---|---|
| 複数人でのデータ共有・同時編集、ログイン機能 | サーバーが必要になり、構成が大きく変わるため。共有したい場合は、画面を見せる・別途連絡するなどで対応をお願いします |
| サーバー・データベースとの連携 | 同上。将来対応する場合は、データの保存方法から作り直しになります |
| スマートフォン向けレイアウト | PC利用を前提としているため |
| 列やカードの並び替え(ドラッグ&ドロップでの列間移動以外) | 最小限の機能での完成を優先するため |

### 10.2 今後の拡張候補(実施を約束するものではありません)
- データのバックアップ・復元(ファイルへの書き出し・読み込み)。6.1 のデータ消失リスクの軽減策として、優先度が高い候補です
- カードにラベル(色分けタグ)を追加
- 列やカードの並び順を保存できるようにする
- 検索・フィルター機能
