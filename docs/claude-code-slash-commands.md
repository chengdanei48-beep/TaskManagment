# Claude Code スラッシュコマンド一覧

作成日: 2026-10-05

> Claude Codeのバージョンや環境(プラグイン・スキル)によって使えるコマンドは変わります。
> 最新の一覧はClaude Code上で `/` を入力するか `/help` で確認してください。

## 1. セッション管理

| コマンド | 説明 | 使いどき |
|---|---|---|
| `/help` | ヘルプと利用可能なコマンドを表示 | 使い方に迷ったとき |
| `/clear` | 会話履歴をクリアして新しく始める | 別の作業に切り替えるとき |
| `/compact` | 会話を要約してコンテキストを圧縮 | 会話が長くなったとき |
| `/resume` | 過去の会話を選んで再開 | 前回の続きをやりたいとき |
| `/rewind` | 会話やコードを以前の時点に戻す | 変更を取り消したいとき |
| `/cost` | トークン使用量・コストを表示 | 利用量を確認したいとき |
| `/status` | バージョン・モデル・アカウント状態を表示 | 現在の設定を確認したいとき |
| `/model` | 使用モデルを切り替え | 性能と速度を使い分けたいとき |
| `/fast` | 高速モードの切り替え | 出力を速くしたいとき |

## 2. プロジェクト設定

| コマンド | 説明 | 使いどき |
|---|---|---|
| `/init` | プロジェクト解析して `CLAUDE.md` を作成 | プロジェクト開始時 |
| `/memory` | メモリ(`CLAUDE.md` 等)を編集 | ルールや知識を追記したいとき |
| `/permissions` | ツール実行の許可・拒否ルールを管理 | 確認ダイアログを減らしたいとき |
| `/config` | 設定(テーマ・モデルなど)を開く | 基本設定を変えたいとき |

## 3. コードレビュー・開発

| コマンド | 説明 | 使いどき |
|---|---|---|
| `/code-review` | 差分やPRのバグ・改善点をレビュー(`ultra`でクラウド深層レビュー) | PR作成前後 |
| `/security-review` | 現在のブランチの変更をセキュリティ観点でレビュー | マージ前 |
| `/simplify` | 変更コードの再利用・簡素化・効率化を行い修正 | 実装後の整理 |
| `/run` | アプリを起動して変更が動くか確認 | 動作確認したいとき |

## 4. 自動化・拡張

| コマンド | 説明 | 使いどき |
|---|---|---|
| `/loop` | プロンプトやコマンドを一定間隔で繰り返し実行 | 状態の定期確認 |
| `/schedule` | cronでクラウドエージェント(ルーティン)を定期実行 | 定期タスクの自動化 |
| `/fewer-permission-prompts` | 履歴から読み取り系コマンドを許可リスト化 | 許可確認が多いとき |
| `/update-config` | `settings.json`(フック・権限・環境変数)を設定 | 自動動作を設定したいとき |
| `/keybindings-help` | キーボードショートカットをカスタマイズ | キー割り当てを変えたいとき |

## 使い方のコツ

- `/` を入力すると候補が一覧表示される。
- 長い作業の途中は `/compact`、話題が変わるときは `/clear` が効果的。
- 本リポジトリでは `CLAUDE.md` の開発フロー(Issue → ブランチ → PR)に従うこと。
